
# Cantina - Youcode

## Présentation du projet

Cantina est une application web de gestion des menus de la cantine YouCode.

Elle permet de gérer une réserve de recettes et de planifier les repas du lundi au vendredi, tout en respectant un budget maximum de 50 DH par jour.

## Technologies utilisées

- HTML5 : structure des pages.
- CSS3 : mise en forme et design responsive.
- Bootstrap : composants et mise en page responsive.
- JavaScript Vanilla : interactions et gestion dynamique.
- Git et GitHub : gestion des versions.
- Vercel : hébergement de l'application.

## Fonctionnalités prévues

- Ajouter, modifier et supprimer des recettes.
- Organiser les repas du lundi au vendredi.
- Gérer les entrées, plats principaux et desserts.
- Respecter le budget maximum de 50 DH par jour.
- Valider les formulaires avec JavaScript et Regex.
- Calculer les coûts et les statistiques.
- Afficher des notifications de confirmation et d'erreur.

## Installation

1. Cloner le dépôt GitHub :

   git clone https://github.com/nadiyaelhani-lab/Cantina.git

2. Ouvrir le dossier Cantina dans VS Code.

3. Ouvrir le fichier index.html dans un navigateur.
